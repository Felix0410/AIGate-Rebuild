# P1 · 组织管理与双进程安全入口

> 状态：NOT STARTED；设计候选已审；真实代码和测试尚未运行。本地AI只有在用户批准本Phase后才可执行。

## Business Goal（业务目标）

新员工与管理员可安全初始化企业并管理Team/RBAC；所有管理请求经过独立Gateway→Core。

## Scope（范围）

Gateway/Core两独立Spring Boot Jar；Core V1六表；Team/Employee/RoleAssignment/mgt_/bst_/审计；仅受控Bootstrap和17条管理/运维API。

**明确不做**：不提前实现未来Phase；不改变三服务架构或数据库归属；不因测试方便弱化认证、账务和安全约束。

## Main Flow（核心流程）

运维来源+bst_初始化 → 唯一Bootstrap事务建Team/首位Admin+mgt_ → 受控管理员管理Team/Employee/Role → 同事务审计 → 管理Key撤销/恢复。

## Architecture（架构/数据所有权）

- 当前应用：Gateway + Core；身份与资金真正主写仍是Core MySQL。
- 数据迁移：[本Phase数据库规范](../database/core-v01.md)；外部接口：[相关API](../api/p01-p03.md)；[Gateway Method白名单](../api/gateway-routes.md)。
- 强制不变量：调用/资源/金额不得绕过本Phase已有前提。长I/O/Scanner/SSE不在MySQL资金锁内执行。

## Tasks（给本地AI的精确任务范围）

P1-T01父Maven/BOM/Wrapper、双Jar和Compose；T02真实V1六表Flyway；T03 Bootstrap初始化/恢复锁；T04 Team/Employee/RBAC/管理Key签发；T05 Gateway精确白名单与svc_网络；T06 E2E和CI。

**交付文件由本地AI完成**：业务Java/控制器/DTO/Mapper/服务、Flyway迁移、必要的Redis Lua/消息及Adapter、单测/集成测试/配置/CI，以及真实执行日志。总控负责本项目正式设计文档更新，不让本地AI选择新技术。

## Acceptance Criteria（验收标准）

新库和重复迁移成功；两JVM可独立启动；Bootstrap并发只有一次成功；TeamManager越权阻断；已提交管理Key不可重复回显；日志无密钥；未知内部路径拒绝。

必须同时满足：
1. 当前业务块全部正常与非法输入路径；鉴权/RBAC与未知字段/状态检查。
2. 真实迁移、事务并发、重试幂等与故障状态；未设计异常处理不能默默返回成功。
3. [对应阶段测试](../09-test-plan.md)的真实PASS/FAIL/SKIP及可复现命令；无环境则记BLOCKED而非PASS。
4. Code Review、架构检查、技术债、Progress/ADR如需、知识点与面试表达；用户批准方可下一Phase。

## Knowledge Points（学习重点）

Java21、Maven BOM、Boot4、Gateway Server WebMVC、SecurityFilterChain、InnoDB行锁、Flyway。

前置Phase必须已经用户签收；运行阶段遇到合同冲突，执行AI停止该子包反馈，先由总控修正[设计总览](../README.md)与相关协议、再继续。不得凭Fake费用/Provider凭证/安全区域配置声称已获生产审批。
